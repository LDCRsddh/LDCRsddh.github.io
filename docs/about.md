# 关于本站

Rhys’s Home 是一个个人小站。它不做社区，不做推荐，只做一件事：

> 把想说的，安静地放在一个能打开的地方。

## 为什么做这个站

以前写过很多零散的笔记，散落在各种文档软件、聊天记录、本地 txt 里。  
某一天想找一句话，翻了半个小时也没找到。

于是有了这个站。**一个入口，一份索引，一种稳定的呈现方式。**

## 设计取向

- **单文件**：`index.html` 里包含全部样式与脚本，没有构建流程，没有依赖
- **无框架**：原生 HTML / CSS / JavaScript，打开就能看，改起来不用装环境
- **暗色为主**：长时间阅读不刺眼，星光背景在暗底上才有层次
- **动效克制**：所有动画都是为了「交代状态变化」

## 页面构成

| 页面 | 用途 |
| --- | --- |
| HOME | 入口，展示小站名称与昵称 |
| ABOUT | 个人简介与联系方式 |
| DOC | 文档索引，读取 `docs/` 下的 markdown |
| TOOL | 自建工具与脚本的集合 |
| DROP | 从仓库下载文件 |

## 关于星光的几句话

背景里的星星是活的。它们有自己的大小、质量和轨道。

鼠标靠近时，小的星星会先被拉进来，在近处环绕；大的星星更沉，留在外圈。  
闲着没事干，只是把物理写得自然一点之后，看起来就该是这样。
