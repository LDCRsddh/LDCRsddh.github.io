# 站点更新日志

记录每一次有意义的改动。格式为 `年.月` + 一句话说明。

## 2025

### 2025.04

- 新增 **DOC 按日期分组**，同一日期的文章可滚动折叠
- 接入 GitHub Issues 作为可选的云端复制计数
- 修正 L 形角标：改为贴合文字实际宽度，而非元素盒子宽度

### 2025.03

- 新增 **白块擦除**过渡：每个文字元素独立持有一块白布，自右向左扫过
- 页面切换改为 **随机二选一**：打字机模式 / 白块模式
- 星光引入 **质量模型**：`mass ≈ r²`，映射到各自的环绕半径
- 新增 TOOL 页面，支持读取 `tools/tools.json`

### 2025.02

- 星光加入 **鼠标吸引**：在影响半径内被牵引到轨道上环绕
- 修复早期版本星星聚成一团、来回抽搐的问题
- 导航加入 L 形角标悬停反馈

### 2025.01

- 初版上线
- 完成 HOME / DOC / DROP 三个页面骨架
- 打字机效果：元素逐字出现，页面切换时逐字删除

## 待办

- [ ] TOOL 页面增加搜索
